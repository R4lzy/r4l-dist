# R4L

Release downloads for the R4L executor.

## Install

1. Download [`R4L-Installer.zip`](../../releases/latest/download/R4L-Installer.zip) and extract it.
2. Run `R4L-Bootstrap.exe`. It downloads the client and starts R4L.
3. Open Roblox, then hit INJECT in R4L.

Windows SmartScreen may warn about an unrecognized publisher since the exe is unsigned. Choose More info, then Run anyway.

Always run `R4L-Bootstrap.exe`. `R4L.exe` on its own needs the `payload` folder beside it, so it is not meant to be launched directly from here.

Already installed? Run `R4L-Bootstrap.exe` again. It hashes what you have and only downloads files that changed.

R4L is free and keyless. Not affiliated with Roblox Corporation.
