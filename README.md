# R4L

Release downloads for the R4L executor.

## Install

1. Open the [latest release](../../releases/latest)
2. Download `R4L-Bootstrap.exe` and `bootstrap.ini` into one folder
3. Run `R4L-Bootstrap.exe` - it downloads everything else and starts R4L

Already installed? Just run `R4L-Bootstrap.exe` again - it checks for updates and launches.
